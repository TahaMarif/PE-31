# PE-31
Github du projet d'étude 31, Ecole Centrale de Lyon, à propos de l'étude de l'impacte des prothèses discales sur la biomécanique du rachis cervical.
Détail des fichiers : 

**Jeu_de_données.txt** : Données obtenues lors de notre essai à vide sur les espaces C5-C6 et C4-C5

**Etalonnage_Plot.py** : Script contenant la loi d'étalonnage obtenue pour nos capteurs ainsi que le plot du jeu de données 

**montecarlo.py** : script qui permet de traiter les incertitudes et d'obtenir une régression à partir d'un jeu de données, basé sur la méthode de Monte-Carlo 

**CAO** : Ensemble des fichiers stl utilisés pour l'impression 3d des vertèbres
